# **App Name**: UX Career Copilot

## Core Features:

- Portfolio Review Chatbot: A chatbot that analyzes your UX portfolio and provides feedback on projects, skills, and overall presentation. The LLM should have a tool which makes reasoned choices about when it should suggest inclusion or deletion of portfolio items.
- Resume Optimization: Offers suggestions for improving your resume based on the content of your portfolio and current job market trends.
- Interview Question Generator: Generates potential interview questions based on the projects and skills highlighted in your portfolio.
- Personalized Feedback: The chatbot will retain past history for persnalized follow up responses.
- Simple UI Chat Interface: A straightforward, conversational UI for interacting with the chatbot.

## Style Guidelines:

- Primary color: Navy blue (#3B5998) to inspire trust and reliability, essential for career-related advice.
- Background color: Very light gray (#F0F2F5), a desaturated near-white that provides a professional, uncluttered backdrop, ensuring legibility.
- Accent color: Teal (#008080) to highlight key information, reflecting the modern and thoughtful aspects of career progression.
- Body and headline font: 'Inter', a sans-serif font, providing a modern and objective feel. This enhances readability and user comfort, ensuring a clean and engaging experience.
- Use simple, professional icons from a set like Material Design Icons to represent different portfolio sections and functionalities.
- Clean, single-column layout optimized for readability.  Prioritize a clear visual hierarchy to guide users through the portfolio review and advice.
- Subtle animations, such as a smooth transition between chat messages or a loading indicator when the AI is processing, will make the experience feel polished without distracting from the content.
